Project :

NMEA2000 Antenna GNSS professionnal  with 2 main pcb option iso  rs485 with Stm32f103 and esp32 for iso can



![description](https://github.com/MaxESP/Ebyte-GNSS-stm32f103-main-ebyte-GNSS-Hat-Professional-Antenna-/blob/main/Antenna%20enclosure.png)|![description](https://github.com/MaxESP/Ebyte-GNSS-stm32f103-main-ebyte-GNSS-Hat-Professional-Antenna-/blob/main/Antenna%20enclosure2.png)


Hardware:
1 STM32F103C8T6

2 ch340c

3 Flash W25Q serie

4 i2c terminal

5 usbc data and power

6 1.27mm pin header to transfert signal pin to hat GNSS

7 1.27mm pin header to transfert signal pin to Hat spi Lora
